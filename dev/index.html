LearningToOptimize.jl

LearningToOptimize.jl trains optimization proxies: machine-learning models that map the parameters of a parametric optimization problem, written in JuMP, to (near-)optimal primal and/or dual solutions, orders of magnitude faster than a solver. It provides the shared layer that every learning-to-optimize (L2O) method needs — a problem wrapper with fixed input/output layouts, dataset generation, batched evaluation of objectives, violations and dual bounds — so that a new method only implements what is specific to it. The reference method shipped here is the penalty ("soft loss") approach, eq. (2) of Donti, Rolnick & Kolter, ICLR 2021; methods with completion steps (feasibility restoration, dual completion) live in sibling packages. See the survey by Kotary et al. (IJCAI 2021) for the field, and our Hugging Face organization for datasets, pre-trained models and benchmarks.

flowchart LR M["JuMP model<br/>with parameters"] --> PP["ParametricProblem"] PP --> PIPE["L2OPipeline(problem, method)"] PIPE --> D["generate_data"] D --> T["train proxy"] T --> C["complete"] C --> E["evaluate: objective,<br/>violations, dual bound"]

Installation

The API described here is on the development version. The registered LearningToOptimize 1.0.0 predates it (it has no L2OCore, ParametricProblem or L2OPipeline). Until the next release, install the core subpackage first and then the main package, on any Julia version from 1.10:

using Pkg
Pkg.add(url = "https://github.com/LearningToOptimize/LearningToOptimize.jl", subdir = "lib/L2OCore")
Pkg.add(url = "https://github.com/LearningToOptimize/LearningToOptimize.jl")

The example below also needs JuMP, HiGHS and Flux: Pkg.add(["JuMP", "HiGHS", "Flux"]).

Minimal example

using LearningToOptimize, JuMP, HiGHS, Flux, Random

model = Model()
@variable(model, d[1:2] in MOI.Parameter.([1.0, 2.0]))   # parameters
@variable(model, 0 <= g[1:3] <= 4)
@constraint(model, g[1] + g[2] == d[1])
@constraint(model, g[3] == d[2])
@objective(model, Min, g[1] + 3g[2] + 2g[3])

problem = ParametricProblem(model)                       # detects LinearConic
pipe = L2OPipeline(problem, PenaltyMethod())
sampler = BoxSampler([0.5, 1.0], [1.5, 2.0])
train = generate_data(pipe; sampler, n = 128)            # self-supervised: parameters only
test = generate_data(pipe; sampler, n = 32, optimizer = HiGHS.Optimizer)

proxy = Flux.f64(Chain(Dense(2 => 32, relu), Dense(32 => 3)))
train_flux!(pipe, proxy, train; epochs = 200, optimiser = Flux.Optimisers.Adam(1e-2))

prediction = complete(pipe, test.inputs, proxy(test.inputs))
evaluate(pipe, test.inputs, prediction)                  # objective, violations, gaps

What you need to provide

  • A JuMP model whose instance data are parameters (@variable(model, p in MOI.Parameter(value))).
  • A parameter distribution: BoxSampler, ScaledSampler, or any function (rng, n) -> matrix.
  • A proxy: any callable mapping a num_parameters × batch matrix to the method's output (Flux, Lux, plain Julia).
  • A solver, only for methods (or evaluations) that need labels or reference optima.
