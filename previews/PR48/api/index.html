LearningToOptimize.PenaltyMethod — Type
PenaltyMethod(; ρ_eq = 10.0, ρ_ineq = 10.0, squared = true)

Self-supervised penalty method: the reference primal method of the LearningToOptimize ecosystem, implemented only through the L2OCore interface.

The proxy $x_θ(p)$ predicts all decision variables and is trained to minimize, over a distribution of parameters,

\[\mathcal{L}(θ) = \mathbb{E}_p\Big[\, s\, f\big(x_θ(p); p\big) + ρ_{\mathrm{eq}}\, \big\|ν_{\mathrm{eq}}\big(x_θ(p); p\big)\big\| + ρ_{\mathrm{ineq}}\, \big\|ν_{\mathrm{ineq}}\big(x_θ(p); p\big)\big\| \Big]\]

where $s = ±1$ turns maximization into minimization, $ν$ are the element-wise constraint violations returned by L2OCore.row_violation (equality rows and all other rows, respectively, plus distances to non-decomposable cones) and $\|·\|$ is the squared 2-norm when squared = true and the 1-norm otherwise. With squared = true this is the soft loss of eq. (2) in Donti, Rolnick & Kolter, "DC3: A learning method for optimization with hard constraints" (ICLR 2021, arXiv:2104.12225), with $λ_h = ρ_eq$ and $λ_g = ρ_ineq$; box rows (two-sided constraints, variable bounds) are penalized through $\max(l - f, 0) + \max(f - u, 0)$, which is the $\mathrm{ReLU}(g)$ of eq. (2) for each side.

The method supports the problem classes LinearConic and ConvexQuadratic, so the default MatrixEvaluator is used and the loss is differentiable with array AD. No solver is needed for training.

Penalty proxies are in general infeasible; pair them with a completion or repair method when feasibility is required, and measure their violations with evaluate.

LearningToOptimize.train_flux! — Method
train_flux!(pipe::L2OPipeline, model, data::L2ODataset; epochs = 100,
            batchsize = 32, optimiser = Optimisers.Adam(1e-3),
            rng = Random.default_rng(), callback = nothing) -> Vector{Float64}

Train a Flux model in place on pipe by minimizing loss(pipe, X, model(X); targets, proxy = model) with mini-batches of columns of data. Works for every method whose loss is differentiable with Zygote. Returns the mean training loss of each epoch. callback(epoch, loss) is called after every epoch.

For PenaltyMethod pipelines, the generic train_proxy!(method, pipe, model, data; kwargs...) calls train_flux!.
